
# FieldLink CRM by GoDeskless Inc.

**FieldLink CRM** is a modern field service management and work order platform, built for GoDeskless Inc. Includes dashboards, asset management, ticketing, scheduling, and more.

<img src="https://github.com/arhamkhnz/next-shadcn-admin-dashboard/blob/main/media/dashboard.png?version=5" alt="Dashboard Screenshot">


FieldLink CRM by GoDeskless Inc. is designed for modern field service teams. It is scalable, customizable, and ready for enterprise use.


## Features

- Built with Next.js 16, TypeScript, Tailwind CSS v4, and Shadcn UI
- Responsive and mobile-friendly
- Asset management, ticketing, scheduling, analytics, and more
- Customizable theme presets (light/dark modes)
- Flexible layouts (collapsible sidebar, variable content widths)
- Authentication flows and screens
- Role-Based Access Control (RBAC) *(planned)*

## Tech Stack

- **Framework**: Next.js 16 (App Router), TypeScript, Tailwind CSS v4
- **UI Components**: Shadcn UI
- **Validation**: Zod
- **Forms & State Management**: React Hook Form, Zustand
- **Tables & Data Handling**: TanStack Table
- **Tooling & DX**: ESLint, Prettier, Husky

## Colocation File System Architecture

This project follows a **colocation-based architecture** each feature keeps its own pages, components, and logic inside its route folder.  
Shared UI, hooks, and configuration live at the top level, making the codebase modular, scalable, and easier to maintain as the app grows.

For a full breakdown of the structure with examples, see the [Next Colocation Template](https://github.com/arhamkhnz/next-colocation-template).


## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/godesklessinc/fieldlink-crm.git
   ```
2. **Navigate into the project**
   ```bash
   cd fieldlink-crm
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Start the development server**
   ```bash
   npm run dev
   ```

Your app will be running at [http://localhost:3000](http://localhost:3000)
